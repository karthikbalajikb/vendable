            How trust & security works
            
    
              Why: an AI buyer shouldn't pay a merchant it can't trust.

    
              1 · Senso verification (grounded facts check). We ingest each merchant's real facts — catalog, payment, legitimacy — into Senso's knowledge base from the product, then query it. Answers are grounded and cited, never hallucinated. It proves the merchant's facts are on file and answerable — not a KYC/identity check.
    
              2 · NANDA-compatible certification. Only payable + Senso-verified + schema-valid stores get a self-issued agent-facts card in NANDA's AgentFacts schema that other agents can read before transacting. (Self-issued for the demo — not registered in the public NANDA Index.)
    
              3 · The payment gate. The buyer agent checks trust before paying. An untrusted merchant is refused the Prava token — no charge happens and the block is captured. Try “simulate untrusted” in the Buyer Agent.
