# Vendable — Go-to-market kit (pre-demo)

Ready-to-post copy for launch + user acquisition. Grab, tweak, ship.

## Before you post: one find-replace
Every file uses **`{{VENDABLE_URL}}`** as a placeholder for the live landing/waitlist link.
Replace it everywhere with your deployed URL (Vercel project is `vendable-web`, so the
default is likely `https://vendable-web.vercel.app` — or your custom domain via copilotverse.io).

## Demo assets (reuse across all channels)
- **Money-shot query:** `Batman posters under ₹500` → ChatGPT returns real posters from
  **two** indie stores (theprintsmithstore.com + posterized.in) as buyable cards → buy inline.
- **Demo video (R2):** https://pub-ccc9d9d9ac4946f2becb2f1a72bc2e7a.r2.dev/Shopping%20with%20ChatGPT%20Integration.mp4
  (Upload the MP4 *natively* to each platform — native video beats a pasted link for reach.)
- **One-liner:** *"Your store sells on Google. It's invisible to ChatGPT. Vendable fixes that
  from a single URL — discoverable, and buyable, inside the assistant."*
- **Positioning:** Any store, from just a URL, becomes discoverable AND buyable inside AI
  assistants (ChatGPT, Gemini, Perplexity). Discovery (AEO) + agentic checkout (ACP/UCP) +
  agent-to-agent payments (Prava) — the merchant does nothing technical.

## Golden rules
- Lead with the finding/story, not the product.
- Put external links in the first comment (LinkedIn) or last tweet (X) — bodies with links get throttled.
- Every CTA points to `{{VENDABLE_URL}}`; the survey's last question feeds the same waitlist.
- Reply to every comment fast — early engagement drives reach.
