# 24-hour distribution / acquisition plan (before the demo)

Priority order — warm + high-intent first, broad + cold last.

## 1. Sharpen the artifact (~30 min)
- One 30–60s demo clip (you have it), one-line pitch, the waitlist link, and a **QR code**
  pointing to `{{VENDABLE_URL}}` for the demo room.
- One-liner: *"Any store, from a URL, becomes buyable inside ChatGPT."*

## 2. Warm DMs first — highest conversion (1–2 hrs)
Message 15–25 store owners you already know or communities you're in. Template:
```
Hey [name] — quick one. I just got [store type] products to show up and be
*buyable* inside ChatGPT (not a browser). Making a handful of stores the first to
be listed. Want yours in? 60-sec demo: {{VENDABLE_URL}}
```

## 3. Build-in-public blast
- LinkedIn Post A now; Post B at demo time (see `linkedin.md`).
- X thread with the video (see `x.md`).
- Ask 3–5 friends to reshare.

## 4. Communities (value-first)
- Reddit posts (reworded per sub — see `reddit.md`).
- Indie Hackers, relevant Discords/Slacks (ecommerce, AI, no-code), WhatsApp merchant groups.
- Optional "Show HN" for a technical crowd.

## 5. Capture everything to the waitlist
- Every CTA → `{{VENDABLE_URL}}`; the survey's last question feeds the same list.
- Watch Supabase rows fill (leads/waitlist tables).

## 6. Product Hunt "Coming soon"
- Stand up a coming-soon page to collect notify-me signups overnight.

## 7. At the demo
- End on the money shot: type `Batman posters under ₹500` → two stores' cards → buy inline.
- Flash the QR. One sentence: *"Any store, from a URL, buyable inside ChatGPT."*

## 8. Follow up within 24h
- DM/email everyone who signed up with an early-access slot while interest is hot.
